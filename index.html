Rust Rush, a tower defense game

A real-time tower defense game in the browser, with a server-authoritative Go backend and a React and Canvas frontend. All game logic, including BFS pathfinding, projectile physics, targeting, and damage, runs on the server at 60 FPS. Difficulty order across 6 maps was set by running each map through a fixed-budget simulation.

The homelab

What runs at home: media server, book pipeline, monitoring, home automation, and a handful of self-built tools, with no ports opened to the internet.

Everything routes through a Cloudflare Tunnel rather than forwarded ports, so there are no inbound holes in the firewall. Storage runs on Unraid with parity protection, and AdGuard Home filters DNS for every device on the network.
